# CHA — An Independent Practice

아이음, 마샬, 와인 커뮤니티를 하나의 개인적 실천으로 연결하는 데스크톱 전용 퍼스널 브랜딩 사이트입니다.

## 화면 기준

- 권장: 1440px 이상 데스크톱
- 최소: 1100px
- 모바일 대응은 의도적으로 포함하지 않았습니다.

## 실행

```bash
cd outputs/personal-brand-site
npm run dev
```

`http://localhost:4174`에서 확인할 수 있습니다.

## 인터랙션 구조

- 로딩 카운터와 화면 전환 인트로
- 스크롤 고정형 Practices 3장 시퀀스
- 스크롤 고정형 Outcomes 3장 시퀀스
- 문장 마스크 리빌과 이미지 클립 리빌
- 마우스 기반 오브젝트·사진 반응
- 섹션별 다중 속도 패럴랙스
- People 아치 이미지와 대형 배경 타이포
- 명암 섹션에 반응하는 헤더와 스크롤 진행 표시

## 공개 전 수정

- `index.html`의 `hello@example.com`을 실제 이메일로 교체
- 프로젝트 설명과 상태 문구 확인
- Context 폼을 실제 폼 처리 서비스에 연결
